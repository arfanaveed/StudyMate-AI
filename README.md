##  About the Project
StudyMate is an AI-powered study assistant designed to help university students learn more efficiently. It provides AI-assisted learning tools, including note summarization, concept explanation, quiz generation, study planning, and assignment management, all in a single application.
##  Problem Statement
Students often struggle to organize study material, understand difficult concepts, prepare for exams, and manage assignments using multiple applications. StudyMate solves this problem by providing one intelligent platform that simplifies learning and improves productivity.

##  Target Audience

- Exam Preparation Students

##  AI Feature
StudyMate uses **Google Gemini AI** to assist students with learning tasks.
The AI can:
- Summarize study notes
- Explain difficult concepts
- Generate quizzes
- Answer study-related questions
### System Prompt
> *You are StudyMate, an intelligent AI study assistant for university students. Help users understand academic concepts, summarize notes, generate quizzes when requested, and provide clear, accurate, and student-friendly explanations.*
